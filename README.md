# Ethics&AI — International Conference on AI and Peacebuilding

Web estática de una sola página. `index.html` es autocontenido (estilos, scripts e imágenes incluidos).

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube el contenido de esta carpeta (`index.html`, `assets/`, `README.md`) a la raíz del repositorio.
3. En el repositorio: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save.
4. En 1–2 minutos estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

Dominio propio: añade un archivo `CNAME` con el dominio y configura el DNS según la guía de GitHub Pages.
